# 🧩 Exercício: Criação de Elementos com JavaScript

Este projeto é um exercício prático de JavaScript que utiliza desestruturação, laço `for` e o método `createElement` para criar e exibir dinamicamente elementos HTML a partir de um array de objetos.

## 📌 Objetivo

- Desestruturar objetos de um array contendo:
  - A **tag HTML** do elemento a ser criado.
  - O **texto** que será inserido no elemento.
- Criar dinamicamente os elementos com `createElement`.
- Utilizar `for` para iterar sobre os objetos.
- Adicionar os elementos criados a um contêiner pai na página.

## 🛠️ Tecnologias Utilizadas

- HTML
- CSS
- JavaScript (DOM, `for`, desestruturação, `createElement`)
